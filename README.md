# 🛸 Rick & Morty x Éric & Ramzy : Le Mashup Roman-Photo

> ⚠️ **PROJET EN COURS DE CRÉATION**  
> Ce dépôt est le chantier ouvert d'un projet de fan totalement absurde : un roman-photo servant de script/pitch visuel pour une aventure interdimensionnelle inédite.

---

## 📌 Le Pitch

Que se passe-t-il quand la logique de science-fiction déjantée de *Rick et Morty* percute l'humour absurde et improvisé d'Éric et Ramzy ? 

Ce projet est une tentative de collision artistique entre deux univers cultes, découpée sous la forme d'un **roman-photo** survolté. Il s'agit d'une démarche purement passionnée, non commerciale et gratuite.

---

## 🎯 L'Objectif Ultime

Soyons honnêtes : le but de ce dossier/roman-photo est de servir de support visuel complet (storyboard, découpage, répliques) dans l'espoir fou que le projet arrive un jour entre les mains de **Éric Judor** et **Ramzy Bedia** pour en faire une vraie réalisation.
