# CONTRIBUTING.md

# Contribuer à Ric et Ramzy

Bienvenue dans la salle des machines de **Ric et Ramzy**.

Ce dépôt n'est pas seulement un espace de stockage de fichiers : c'est une writer's room interdimensionnelle où l'on construit progressivement la bible d'une série qui n'existera probablement jamais, mais qui mérite tout de même une organisation professionnelle.

L'objectif est de créer un univers cohérent, drôle et absurde, capable de survivre à des dizaines d'épisodes.

---

# Avant toute chose : comprendre l'esprit du projet

## La règle fondamentale

**Ramzy veut toujours créer quelque chose d'extraordinaire.
Ric veut toujours rentrer chez lui.**

Toute contribution doit respecter cette tension.

Une idée peut être folle.

Elle peut être impossible.

Elle peut casser les lois de la physique.

Mais elle doit toujours servir la dynamique du duo.

---

# Types de contributions

## 1. Nouvelles idées

Les idées brutes vont dans :

```
boite-a-idees/
```

Elles peuvent concerner :

* un univers ;
* un gadget ;
* un personnage ;
* un gag ;
* une situation ;
* un épisode complet ;
* un running gag.

Une idée n'a pas besoin d'être parfaite pour être ajoutée.

Une bonne idée mal exploitée vaut mieux qu'une idée jamais écrite.

---

## 2. Enrichissement du canon

Les éléments devenus importants doivent rejoindre :

```
bible/
```

Exemples :

* une règle du multivers ;
* un personnage récurrent ;
* une invention de Ramzy ;
* un lieu connu ;
* une caractéristique définitive d'un personnage.

Attention :

Une idée n'est pas automatiquement vraie dans l'univers.

La boîte à idées contient les possibilités.

La Bible contient les vérités.

---

## 3. Création d'épisodes

Les épisodes vont dans :

```
episodes/
```

Chaque épisode devrait préciser :

* son concept ;
* son déclencheur ;
* le rôle de Ramzy ;
* le refus ou la résistance de Ric ;
* l'univers visité ;
* les gags principaux ;
* le climax ;
* la chute ;
* les éléments ajoutés au canon.

---

# Ajouter une idée

Utiliser ce format :

```md
# Nom de l'idée

## Catégorie

- gadget
- univers
- personnage
- gag
- épisode
- running gag

## Statut

- nouvelle
- à développer
- prête à utiliser
- utilisée
- canonisée
- décharge cosmique

## Description

Décrire l'idée.

## Pourquoi c'est drôle

Expliquer le mécanisme comique.

## Utilisation possible

Donner des pistes.
```

# Les bonnes contributions

Une bonne idée Ric et Ramzy contient souvent au moins un de ces éléments :

* un personnage très sûr de lui qui raconte n'importe quoi ;
* une situation extraordinaire traitée comme un problème banal ;
* une invention brillante qui crée un problème encore plus grand ;
* Ric qui pose la question évidente que personne n'a posée ;
* Ramzy qui explique une absurdité avec un sérieux absolu ;
* un décalage entre l'importance cosmique d'un événement et la réaction humaine des personnages.

---

# Les références à Éric et Ramzy

Les références sont encouragées.

Mais on ne cherche pas à recopier des sketchs.

On récupère :

* une mécanique comique ;
* une dynamique de dialogue ;
* un type de personnage ;
* une façon de construire l'absurde.

La bonne question :

> "Est-ce que cette idée fonctionne même si quelqu'un ne connaît pas Éric et Ramzy ?"

Si oui, la référence est réussie.

---

# Les éléments à protéger

## Ric

Ne jamais oublier :

* il n'est pas idiot ;
* il est souvent le plus lucide ;
* son absence d'envie est un choix comique ;
* il ne doit pas devenir un simple spectateur.

---

## Ramzy

Ne jamais oublier :

* il est réellement brillant ;
* il n'est pas seulement un clown ;
* il croit profondément à ses idées ;
* sa connaissance du quatrième mur est un pouvoir autant qu'un problème.

---

# Les modifications importantes

Avant de modifier un élément majeur :

Vérifier :

1. Est-ce compatible avec la Bible ?
2. Est-ce que cela améliore les personnages ?
3. Est-ce que cela crée de nouvelles possibilités comiques ?

Si une réponse est non, l'idée doit probablement rester dans la boîte à idées.

---

# Commits

Les messages de commit doivent être compréhensibles et raconter l'évolution du projet.

Préférer :

```
Ajout du pisto-portail défectueux
```

```
Création de la famille interdimensionnelle de Ric
```

```
Canonisation du quatrième mur physique
```

Éviter :

```
modifs
```

```
test
```

```
plein de trucs
```

Même les commits participent à la narration.

---

# Pull requests

Une contribution importante doit expliquer :

## Ce qui est ajouté

Exemple :

> Ajout d'un nouvel univers visité.

## Pourquoi

Exemple :

> Permet de créer un épisode centré sur le refus de Ric.

## Impact sur le canon

Exemple :

> Aucun changement permanent.

ou :

> Ajoute une nouvelle règle du multivers.

---

# Les idées abandonnées

Une idée refusée n'est pas forcément mauvaise.

Elle peut être déplacée dans :

```
boite-a-idees/decharge-cosmique.md
```

Certaines inventions géniales de Ramzy ont probablement commencé comme des catastrophes.

---

# Dernière règle

Ne jamais oublier :

Dans cet univers, tout peut être détruit.

Une planète.

Une dimension.

La logique.

Mais jamais la dynamique entre Ric et Ramzy.

```
Ramzy ouvre un portail.
Ric soupire.
L'aventure commence.
```
