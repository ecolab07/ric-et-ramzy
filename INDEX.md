# Ric & Ramzy — Projet

Bienvenue dans le laboratoire d'écriture de l'univers Ric & Ramzy.

Ce dépôt sert à construire un univers comique cohérent :
- une bible d'univers stable ;
- une réserve d'idées chaotiques ;
- des épisodes en cours d'écriture.

L'objectif n'est pas de figer l'humour, mais de créer un terrain de jeu avec des règles assez solides pour permettre le chaos.

---

# Architecture du projet

## 🧠 Bible — Le canon

Dossier : `bible/`

Ce qui est considéré comme établi dans l'univers.

Contient :
- les personnages ;
- les règles du monde ;
- les mécanismes d'humour ;
- les références structurantes.

Une idée n'entre ici que lorsqu'elle devient une règle exploitable.

---

## 💡 Boîte à idées — Le laboratoire

Dossier : `boite-a-idees/`

Zone de recherche et d'expérimentation.

On y stocke :
- des gags ;
- des dialogues ;
- des concepts d'épisodes ;
- des personnages ;
- des lieux absurdes ;
- des gadgets ;
- des déclencheurs narratifs ;
- des références.

La règle :
une idée n'a pas besoin d'être bonne pour exister.

Une idée étrange peut devenir une bonne idée plus tard.

---

## 🎬 Episodes — La production

Dossier : `episodes/`

Les histoires concrètes.

Un épisode passe généralement par :
```
idée
↓
développement
↓
structure narrative
↓
écriture scènes/dialogues
↓
épisode terminé

```
---
# Cycle d'une idée
```
boite-a-idees/
│
▼
a-developper.md
│
▼
episode ou bible
│
▼
canonisation
```

Une idée peut :
- devenir un épisode ;
- devenir une règle de l'univers ;
- devenir un running gag ;
- retourner dormir dans les archives.

# Principes d'écriture

## 1. La logique avant la blague

Le monde doit prendre ses absurdités au sérieux.

Plus une situation est impossible, plus les personnages doivent la traiter comme normale.

---

## 2. Le contraste crée le comique

Les personnages ne cherchent pas forcément à être drôles.

Ils sont drôles parce qu'ils appliquent une logique différente.

---

## 3. Le chaos doit avoir une mémoire

Les conséquences existent.

Un gag peut devenir :
- une habitude ;
- une règle du monde ;
- un problème récurrent.
