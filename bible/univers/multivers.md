# Le Multivers

## Statut

Canon

---

# Définition

Le multivers de *Ric et Ramzy* est constitué d'une infinité de réalités parallèles.

Chaque univers possède ses propres règles, son histoire et ses particularités.

Ces dimensions peuvent être :

* fascinantes ;
* dangereuses ;
* absurdes ;
* complètement banales.

Souvent les quatre à la fois.

---

# Principe fondamental

Une nouvelle dimension n'est pas intéressante parce qu'elle est différente.

Elle est intéressante parce qu'elle révèle quelque chose sur les personnages.

La question principale n'est pas :

> "Quel monde allons-nous visiter ?"

Mais :

> "Que devient Ric et Ramzy dans ce monde ?"

---

# Les types de dimensions

## Dimensions spectaculaires

Des univers où les lois physiques sont extraordinaires.

Exemples :

* mondes avec plusieurs soleils ;
* civilisations interstellaires ;
* planètes artificielles ;
* réalités où la matière fonctionne différemment.

Fonction narrative :

Permettre à Ramzy de s'émerveiller.

Réaction de Ric :

Chercher où se trouve la sortie.

---

## Dimensions absurdes

Des univers basés sur une règle simple poussée à l'extrême.

Exemples :

* un monde où tout le monde parle uniquement en questions ;
* une planète où les décisions sont prises par tirage au sort ;
* une société où les excuses sont une monnaie officielle.

Fonction narrative :

Créer des situations comiques.

---

## Dimensions quotidiennes

Des mondes presque identiques au leur.

La différence est minuscule mais importante.

Exemples :

* un univers où Ric est motivé ;
* un univers où Ramzy est raisonnable ;
* un monde où tout le monde connaît le quatrième mur sauf eux.

Fonction narrative :

Créer des décalages subtils.

---

## Dimensions dangereuses

Des réalités qui représentent une vraie menace.

Exemples :

* univers qui se désagrègent ;
* intelligences artificielles incontrôlables ;
* créatures capables de modifier la réalité.

Fonction narrative :

Créer des enjeux.

---

# Les lois du voyage interdimensionnel

## Le pisto-portail

Le pisto-portail de Ramzy permet de traverser les dimensions.

Cependant, il possède un comportement imprévisible.

Il peut :

* ouvrir un portail au mauvais endroit ;
* choisir une destination inattendue ;
* fonctionner avec un léger retard ;
* demander une mise à jour au mauvais moment.

---

# Les coordonnées dimensionnelles

Chaque univers possède une signature particulière.

Ramzy peut normalement calculer :

* la fréquence dimensionnelle ;
* la stabilité du passage ;
* le risque de collision.

Dans la pratique :

ses calculs sont souvent corrects mais rarement utiles.

---

# Les croisements de dimensions

Plusieurs versions d'une même personne peuvent exister.

Cependant, rencontrer une autre version de soi-même est rarement une bonne idée.

Les variantes peuvent être :

* meilleures ;
* pires ;
* identiques avec un détail ridicule ;
* totalement incompréhensibles.

---

# Les versions alternatives

## Ric alternatifs

Possibilités :

* Ric aventurier ;
* Ric scientifique ;
* Ric extrêmement motivé ;
* Ric qui refuse encore plus les aventures.

La version la plus inquiétante :

Un Ric qui a envie de partir.

---

## Ramzy alternatifs

Possibilités :

* Ramzy qui n'a jamais découvert le quatrième mur ;
* Ramzy qui utilise le quatrième mur pour de mauvaises raisons ;
* Ramzy qui pense avoir tout compris.

La version la plus dangereuse :

Un Ramzy convaincu qu'il contrôle vraiment l'histoire.

---

# Les paradoxes

Les paradoxes existent.

Mais ils ne doivent jamais devenir de simples solutions scénaristiques.

Un paradoxe est intéressant lorsqu'il crée un problème plus grand que celui qu'il devait résoudre.

Exemple :

Ramzy voyage dans le passé pour éviter une erreur.

Il crée une réalité où cette erreur devient nécessaire.

---

# L'administration du multivers

Le multivers peut contenir des structures administratives.

Parce que même l'infini a probablement besoin de formulaires.

Exemples :

* bureau des autorisations de voyage dimensionnel ;
* service des incidents temporels ;
* assurance responsabilité interdimensionnelle.

Ces organismes prennent les événements cosmiques avec un sérieux administratif absolu.

---

# Relation entre le multivers et le quatrième mur

Le quatrième mur n'est pas une dimension comme les autres.

C'est un niveau de réalité supérieur.

Les dimensions du multivers sont des mondes.

Le quatrième mur est une frontière entre les mondes et leur représentation.

Ramzy cherche naturellement à comprendre cette distinction.

---

# Règles de création d'une nouvelle dimension

Avant de créer un univers, définir :

## 1. La règle différente

Qu'est-ce qui change ?

---

## 2. La conséquence

Comment cette différence transforme la société ?

---

## 3. Le conflit

Pourquoi Ric et Ramzy ont-ils un problème dans ce monde ?

---

## 4. La blague centrale

Quelle situation absurde naît de cette règle ?

---

# Exemples de dimensions possibles

## Dimension des effets spéciaux

Les effets visuels existent réellement dans l'univers.

Les explosions sont des créatures vivantes.

Les portails sont des animaux domestiques.

---

## Dimension du scénario parfait

Tout se déroule exactement comme prévu.

Personne n'aime cette dimension.

Même Ramzy la trouve inquiétante.

---

## Dimension du budget illimité

Tout est possible.

Les habitants ont pourtant le même problème :

Ils ne savent plus quoi inventer.

---

## Dimension pavillonnaire

Un univers identique au leur où les problèmes cosmiques sont traités comme des problèmes de voisinage.

---

# Phrase résumant le multivers

> L'univers de Ric et Ramzy est infini, mais chaque dimension finit toujours par rencontrer le même problème : Ramzy veut explorer, et Ric veut rentrer.
