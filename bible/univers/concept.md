# Concept général de l'univers

## Statut

Canon

---

# Nom de la série

**Ric et Ramzy**

---

# Concept en une phrase

**Deux hommes traversent des univers impossibles : l'un veut tout comprendre, l'autre veut juste rentrer chez lui.**

---

# Concept développé

*Ric et Ramzy* est une série de science-fiction absurde mettant en scène Éric Judor et Ramzy Bedia dans un univers où les dimensions parallèles, les voyages dans le temps et les anomalies cosmiques existent réellement.

Le problème est que les deux personnages n'ont absolument pas la même vision de ces événements.

Ramzy considère chaque phénomène impossible comme une opportunité scientifique et artistique.

Ric considère chaque phénomène impossible comme une raison supplémentaire de ne pas être sorti de chez lui.

---

# Positionnement de la série

La série est un hommage parodique aux codes de la science-fiction moderne.

Elle reprend les grands ingrédients attendus :

* voyages interdimensionnels ;
* inventions impossibles ;
* mondes parallèles ;
* créatures extraterrestres ;
* paradoxes temporels ;
* effets spéciaux spectaculaires.

Mais elle les confronte à une logique comique très humaine :

* la flemme ;
* les problèmes du quotidien ;
* les conversations absurdes ;
* les préoccupations banales.

Une catastrophe cosmique peut être moins importante qu'un problème de voisinage.

---

# La particularité fondamentale

## La série sait qu'elle est une série

L'univers de *Ric et Ramzy* possède une conscience partielle de sa propre nature fictive.

Ramzy en est pleinement conscient.

Il sait :

* qu'il existe un scénario ;
* qu'il est un personnage ;
* qu'un public observe ses aventures ;
* que certaines règles narratives existent.

Cette connaissance est pour lui une découverte scientifique majeure.

---

# Le quatrième mur

## Nature

Le quatrième mur n'est pas seulement une convention narrative.

Dans cet univers, il s'agit d'une véritable frontière entre plusieurs niveaux de réalité.

Ramzy est capable d'interagir avec cette frontière.

---

## Capacités liées au quatrième mur

Ramzy peut parfois :

* parler directement au lecteur ;
* interrompre une narration ;
* influencer une transition ;
* commenter la mise en scène ;
* remarquer les contraintes de production ;
* demander des modifications visuelles.

---

## Limites

Le quatrième mur n'est pas un pouvoir absolu.

Ramzy peut observer certaines règles narratives, mais il ne contrôle pas entièrement l'histoire.

La fiction conserve une part d'imprévisibilité.

---

# Le multivers

## Principe

L'univers contient une infinité de réalités parallèles.

Chaque dimension peut posséder :

* ses propres règles physiques ;
* sa propre histoire ;
* sa propre logique sociale ;
* ses propres absurdités.

---

## Règle importante

Plus une dimension semble extraordinaire, plus ses habitants peuvent être étonnamment banals.

Exemples :

* une planète où les habitants contrôlent la gravité mais se disputent pour des places de parking ;
* une civilisation immortelle qui organise des réunions interminables ;
* une dimension capable de voyager dans le temps mais incapable de retrouver un mot de passe.

---

# La science dans la série

La science existe réellement.

Les inventions de Ramzy ne sont pas de simples gadgets magiques.

Elles fonctionnent selon des principes complexes.

Cependant :

* leurs conséquences sont rarement prévues ;
* leur utilisation crée souvent des problèmes inattendus ;
* Ramzy comprend parfois le fonctionnement après l'avoir inventé.

---

# Le ton

La série mélange :

## Science-fiction spectaculaire

* galaxies ;
* dimensions ;
* créatures ;
* technologies impossibles.

## Comédie humaine

* fatigue ;
* mauvaise volonté ;
* discussions inutiles ;
* problèmes pratiques.

Le contraste entre les deux est la source principale du comique.

---

# La règle d'or de l'univers

L'univers peut être gigantesque.

Les enjeux peuvent être cosmiques.

Mais les personnages restent profondément humains.

Une explosion de planète peut arriver.

Ric demandera quand même :

> "On rentre à quelle heure ?"

---

# Ce que la série n'est pas

*Ric et Ramzy* n'est pas :

* une simple copie d'une autre série ;
* une succession de références ;
* une démonstration de science-fiction sans humour ;
* une histoire où les personnages deviennent des super-héros classiques.

---

# Ce que la série est

C'est une série où :

* Ramzy cherche les limites de la réalité ;
* Ric cherche les limites de sa patience ;
* le quatrième mur devient un terrain de jeu ;
* le cosmos rencontre les problèmes ordinaires.

---

# Formule résumée

> Un scientifique qui sait qu'il est dans une fiction entraîne son ami nonchalant dans des aventures interdimensionnelles que ce dernier aurait préféré éviter.
