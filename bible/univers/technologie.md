# Technologie et inventions

## Statut

Canon

---

# Principe général

La technologie de *Ric et Ramzy* repose sur une idée fondamentale :

> Une invention brillante entre de mauvaises mains peut devenir un problème encore plus brillant.

Les machines de Ramzy fonctionnent réellement.

Le problème n'est généralement pas la technologie.

Le problème est :

* l'utilisation qu'en fait Ramzy ;
* les conséquences imprévues ;
* les détails qu'il a oubliés.

---

# La science ramzienne

La science de Ramzy mélange :

* physique avancée ;
* intuition géniale ;
* improvisation ;
* confiance excessive.

Ramzy est capable de créer des technologies qui dépassent l'état actuel des connaissances.

Cependant, il possède une méthode de travail particulière :

1. Il imagine une invention.
2. Il construit l'invention.
3. Il découvre pourquoi elle fonctionne.

---

# Le pisto-portail

## Statut

Canon

## Description

Le pisto-portail est l'invention emblématique de Ramzy.

Il permet d'ouvrir des passages entre différentes réalités.

Visuellement, c'est un objet reconnaissable et spectaculaire.

---

# Fonctionnement théorique

Le pisto-portail crée une déchirure contrôlée entre deux points de l'espace dimensionnel.

Il calcule :

* la fréquence d'une réalité ;
* la stabilité du passage ;
* la compatibilité entre les univers.

---

# Fonctionnement réel

Le pisto-portail fonctionne.

Mais il possède des comportements imprévisibles.

Problèmes connus :

* ouverture légèrement décalée ;
* destination approximative ;
* retard d'apparition ;
* portail ouvert au mauvais moment ;
* demande de maintenance pendant une urgence.

---

# Running gags du pisto-portail

## Le retard

Ramzy tire.

Rien ne se passe.

Il pense que l'appareil est cassé.

Le portail apparaît quelques secondes plus tard.

Souvent au mauvais endroit.

---

## La mauvaise destination

Ramzy annonce :

> "J'ai calculé exactement notre destination."

Le portail mène ailleurs.

Ramzy :

> "Exactement comme prévu."

Ric :

> "Tu n'avais pas prévu ça."

Ramzy :

> "J'avais prévu que quelque chose arrive."

---

## La mise à jour

Le pisto-portail affiche parfois :

> Mise à jour nécessaire.

Même en plein danger.

# Autres inventions principales

---

# Détecteur de clichés

## Fonction

Détecte les situations narratives trop prévisibles.

Exemples :

* apparition d'un méchant ;
* discours trop long ;
* trahison annoncée ;
* sacrifice héroïque.

## Problème

Le détecteur déclenche parfois des alertes sur des événements normaux.

Exemple :

Ric ouvre le frigo.

Alarme.

> "Attention : situation classique de personnage affamé."

---

# Traducteur universel

## Fonction

Permet de comprendre toutes les langues.

## Problème

Il traduit également :

* les pensées involontaires ;
* les sous-entendus ;
* les mensonges.

Ce qui crée souvent plus de problèmes qu'il n'en résout.

---

# Machine à remonter le temps

## Fonction

Permet de voyager dans le passé.

## Problème

Ramzy refuse de l'utiliser correctement.

Il préfère modifier de petits détails insignifiants.

Exemples :

* changer le choix d'un menu ;
* éviter une conversation gênante ;
* gagner quelques minutes.

Chaque modification crée pourtant une conséquence absurde.

---

# Télécommande narrative

## Fonction

Une invention permettant d'interagir avec certains éléments de mise en scène.

Possibilités :

* accélérer une scène ;
* changer de décor ;
* ajouter un effet spécial.

## Limite

Elle ne contrôle pas les personnages.

Ric reste Ric.

---

# Scanner de quatrième mur

## Fonction

Permet d'analyser la frontière entre fiction et réalité.

## Utilisation

Ramzy l'utilise pour :

* mesurer la solidité du quatrième mur ;
* détecter une intervention extérieure ;
* analyser les règles narratives.

## Problème

Il détecte parfois des choses qu'il aurait préféré ignorer.

---

# Véhicule interdimensionnel

## Description

Un moyen de transport permettant d'explorer les univers éloignés.

## Particularité

Ramzy considère qu'il s'agit d'un véhicule révolutionnaire.

Ric considère qu'il s'agit d'une voiture qui a trop de boutons.

---

# Philosophie des inventions

Une invention de Ramzy doit respecter trois règles :

## 1. Elle résout un problème

Sinon Ramzy ne l'aurait pas créée.

---

## 2. Elle crée un problème plus intéressant

Sinon il n'y aurait pas d'épisode.

---

## 3. Ric doit pouvoir dire :

> "Je t'avais prévenu."

---

# Les inventions ratées

Les inventions qui échouent ne sont pas forcément inutiles.

Certaines deviennent des outils essentiels plus tard.

Exemples :

* une machine conçue pour autre chose ;
* un prototype dangereux ;
* un appareil que personne ne comprend sauf par accident.

---

# Limites technologiques

Même Ramzy ne peut pas tout faire.

Il existe :

* des phénomènes inconnus ;
* des technologies supérieures ;
* des intelligences capables de le surprendre.

Son plus grand ennemi n'est pas l'ignorance.

C'est l'existence de choses qu'il ne peut pas expliquer immédiatement.

---

# Phrase résumant la technologie

> Ramzy invente des machines capables de changer l'univers. Heureusement pour l'univers, il oublie parfois de lire le mode d'emploi.
