# AGENTS.md — Projet Ric et Ramzy

## Mission du projet

Ce dépôt contient la bible, les scripts, les idées et les éléments de production d'un projet de roman-photo servant de base à une série TV fictive appelée **Ric et Ramzy**.

Le projet est une comédie de science-fiction absurde inspirée de la mécanique des séries de voyages interdimensionnels, tout en utilisant l'univers comique et les personnalités publiques d'Éric Judor et Ramzy Bedia.

Le principe fondamental :

> Ramzy sait qu'il est dans une fiction. Ric aimerait simplement ne pas y être.

---

# Principes créatifs

## 1. Respecter la dynamique du duo

### Ramzy

* Scientifique de génie.
* Inventeur du pisto-portail.
* Conscient du quatrième mur.
* Capable de manipuler certains éléments narratifs.
* Enthousiaste face au chaos.
* Peut expliquer une absurdité avec un sérieux scientifique total.

### Ric

* Nonchalant.
* Peu motivé par l'aventure.
* Cherche toujours la solution la plus simple.
* Refuse généralement les aventures.
* Possède souvent le bon sens que les autres personnages ont perdu.

Règle principale :

**Ramzy déclenche les problèmes. Ric essaie d'y survivre.**

---

# Ton et humour

L'humour repose sur :

* l'absurde logique ;
* les dialogues décalés ;
* les malentendus ;
* les personnages trop sûrs d'eux ;
* le contraste entre une situation extraordinaire et une réaction banale ;
* le détournement des codes de la science-fiction.

Une invasion extraterrestre peut être moins importante qu'une discussion sur le repas du soir.

---

# Quatrième mur

Le quatrième mur fait partie de l'univers.

Ramzy peut :

* parler au lecteur ;
* commenter le scénario ;
* discuter avec le narrateur ;
* influencer certains éléments de mise en scène ;
* remarquer les contraintes de production.

Cependant :

* le quatrième mur ne doit pas supprimer les enjeux ;
* les personnages doivent continuer à vivre leurs aventures comme réelles ;
* la méta-fiction sert la comédie, pas uniquement la référence.

---

# Organisation du dépôt

## bible/

Contient les éléments devenus officiels.

Exemples :

* personnages ;
* règles de l'univers ;
* lieux récurrents ;
* objets importants ;
* chronologie.

Une information entre dans la Bible uniquement lorsqu'elle est considérée comme canonique.

---

## boite-a-idees/

Contient les idées non encore validées.

Une idée peut être :

* nouvelle ;
* à développer ;
* prête à utiliser ;
* utilisée ;
* canonisée ;
* abandonnée.

Ne pas supprimer une idée intéressante sans raison : certaines idées peuvent attendre le bon contexte.

---

## episodes/

Contient les fiches et scripts d'épisodes.

Chaque épisode devrait documenter :

* le concept ;
* le déclencheur ;
* l'univers visité ;
* les personnages présents ;
* les inventions utilisées ;
* les gags principaux ;
* la conclusion ;
* les nouveaux éléments ajoutés au canon.

---

# Règles d'écriture

## À privilégier

* Les idées simples avec une exécution absurde.
* Les personnages qui prennent l'absurde au sérieux.
* Les situations où Ric est le seul personnage raisonnable.
* Les inventions qui créent plus de problèmes qu'elles n'en résolvent.
* Les chutes inattendues.

## À éviter

* Copier directement des épisodes existants.
* Transformer Ric en simple spectateur.
* Faire de Ramzy uniquement un génie froid.
* Accumuler des références sans créer de nouveaux gags.
* Faire de la science-fiction sans décalage comique.

---

# Gestion des idées

Avant d'ajouter un élément important :

1. Vérifier s'il existe déjà.
2. Vérifier s'il contredit le canon.
3. Ajouter une note expliquant son origine.
4. Indiquer s'il est utilisé dans un épisode.

---

# Philosophie générale

Le projet doit toujours garder cette contradiction :

**Le spectacle doit sembler gigantesque, mais les personnages doivent rester ridiculement humains.**

Des galaxies peuvent exploser.

Un portail peut déchirer l'espace-temps.

Mais Ric peut toujours demander :

> "On rentre quand ?"

Et Ramzy peut toujours répondre :

> "Techniquement, on n'est jamais partis."
